# Price Flow Tracker Frontend

A React + TypeScript frontend scaffold for a portfolio monitoring dashboard with landing, login/register, and dashboard pages.

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Zustand
- React Router

## Scripts
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Pages
- Landing page
- Login page
- Register page
- Dashboard

## Features
- Mock ETF signal feed with momentum, liquidity, fragility, and AI exposure
- Zustand market data store for live refresh state
- TradingView-style chart using lightweight-charts

## Notes
This starter app is focused on the requested frontend experience. Replace the example dashboard data with your live ETF and market signal calculations.
